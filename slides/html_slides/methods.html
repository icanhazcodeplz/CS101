Methods in Java

Define once, call anywhere
METHOD A named, reusable block of code that performs a specific task. A method can accept parameters as input and can return a value as output.
Syntax
public static returnType methodName(type param1, type param2) { // code that runs when the method is called return value; // sends a value back (omit for void) }
  • returnType — the data type the method sends back (int, String, boolean, etc.). Use void if it returns nothing.
  • parameters — inputs the method receives, each with a type and name. A method can have zero or more parameters.
  • return — exits the method and sends a value back to the caller.
void — No Parameters
public static void sayHello() { System.out.println("Hello!"); } // Calling it: sayHello(); // prints: Hello!
Returns nothing (void). Just performs an action.
void — With Parameters
public static void greet(String name) { System.out.println("Hi, " + name + "!"); } // Calling it: greet("Alice"); // prints: Hi, Alice!
"Alice" is the argument passed to the parameter name.
Returns int
public static int add(int a, int b) { return a + b; } // Calling it: int sum = add(3, 5); System.out.println(sum); // prints: 8
Returns an int. The return value can be stored in a variable.
Returns boolean
public static boolean isEven(int num) { return num % 2 == 0; } // Calling it: System.out.println(isEven(4)); // true System.out.println(isEven(7)); // false
The expression num % 2 == 0 evaluates to true or false.
Error — Storing void
public static void sayHi() { System.out.println("Hi!"); } int x = sayHi(); // ERROR!
A void method returns nothing — you can't assign it to a variable.
Mistake — Ignoring Return
public static int doubleIt(int x) { return x * 2; } int a = 3; doubleIt(a); System.out.println(a); // still 3!
The return value is thrown away. Use a = doubleIt(a); to keep it.
Parameter
The variable in a method's definition that receives a value. e.g. int num
Argument
The actual value you pass when calling a method. e.g. 5
Return Type
The data type a method sends back. void means nothing is returned.
Method Call
Running a method by writing its name with parentheses and arguments. e.g. add(3, 5)
