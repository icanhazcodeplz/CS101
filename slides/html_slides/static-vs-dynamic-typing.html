Statically Typed · Dynamically Typed

Category
Statically Typed
Dynamically Typed
Definition
Types are known at compile time. Once declared, a variable's type cannot change.
Types are determined at runtime. A variable can hold different types throughout its lifetime.
Languages
Java C C++ Go Rust
Python JavaScript Ruby PHP
Code Example
Java
int x = 5; x = "hello"; // compile error
Python
x = 5 x = "hello" # no error
Pros
Catches type errors before running Better performance (optimized at compile time) Easier to maintain large codebases
Faster to write — less boilerplate More flexible and forgiving Great for prototyping and scripting
Cons
More verbose — must declare types Slower to write for small scripts
Type errors only found at runtime Slower execution speed Harder to debug in large projects
