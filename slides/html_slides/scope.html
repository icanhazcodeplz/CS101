Scope in Java

SCOPE The region of code where a variable exists and can be accessed. A variable declared inside a block { } only exists within that block.
if/else — Out of Scope
int x = 10; if (x > 5) { int y = 20; } System.out.println(x); // OK! System.out.println(y); // ERROR
y was declared inside the if block — it doesn't exist outside of it.
if/else — Fixed
int x = 10; int y = 0; // declare BEFORE if (x > 5) { y = 20; // assign inside } System.out.println(x); // OK! System.out.println(y); // OK!
Declared before the block, so it still exists after.
for Loop — Out of Scope
for (int i = 0; i < 5; i++) { System.out.println(i); } System.out.println(i); // ERROR
i is declared in the loop header — it only lives inside the loop.
for Loop — Fixed
int i; // declare BEFORE for (i = 0; i < 5; i++) { System.out.println(i); } System.out.println(i); // OK! (prints 5)
Declared before the loop so it survives after the loop ends.
