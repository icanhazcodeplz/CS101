Case-Sensitive

Uppercase ≠ lowercase
CASE-SENSITIVE Treats Hello, hello, and HELLO as three different things.
IN JAVA CODE
Variable Names
int score = 10; score = 9; // ok Score = 8; // ERROR
String Comparison
String a = "Hello"; String b = "hello"; a.equals(b); // false
IN EVERYDAY COMPUTING

● Not Case-Sensitive

  • Email addresses
  • Domain names — Google.com = google.com
  • File names (Windows)

● Case-Sensitive

  • Passwords
  • URL paths — google.com/About ≠ google.com/about
  • File names (Mac/Linux)
  • Terminal commands — cd ≠ Cd
