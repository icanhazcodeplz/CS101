### Java Order of Operations

| Priority | Operator(s)         | Description |
|----------|---------------------|-----------|
| 1 | `( )`               | Parentheses |
| 2 | `**`                | Exponentiation |
| 3 | `*`, `/`, `%`       | Multiplication, Division, Modulus |
| 4 | `+`, `−`            | Addition, Subtraction |
| 5 | `>`, `<`, `>=`, `<=` | Relational / Comparison |
| 6 | `==`, `!=`          | Equality |
| 7 | `&&`                | Logical AND |
| 8 | `||`                | Logical OR |
| 9 | `=`, `+=`, `-=`     | Assignment |
