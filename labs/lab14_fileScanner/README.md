# Lab 14: File Scanner

## How to Download and Set Up

### 1. Download the zip file from GitHub
- Navigate to the lab14 zip file on GitHub
- Click the file, then click the **Download** button (down arrow icon)

### 2. Upload to Codespaces
- Open your Codespace
- In the file explorer on the left, right-click the folder where you want to upload and select **Upload...**
- Select the `lab14_fileScanner.zip` file you downloaded

### 3. Unzip the file
Open the terminal in Codespaces and run:

```bash
unzip lab14_fileScanner.zip
```

This will extract the following files:
- `lab14_FileScanner.java` - the lab file (edit this one)
- `CSVParser.java` - helper class for reading CSV files
- `pokemon.txt` - list of Pokemon names
- `pokemon.csv` - Pokemon data with name, type, and generation
