# CS101 Lab2: Java Print Statements

## Learning Objectives
In this exercise you will use Java to practice:
- Using `System.out.println` and `System.out.print`
- Java Escape Sequences
- Adding comments to your code

---

## Instructions
1. Create a new file in your workspace directory of your Codespaces IDE called `printStatements.java`
2. Copy the contents of the [printStatements.java](https://github.com/icanhazcodeplz/CS101/blob/main/labs/lab2_java_print_statements/printStatements.java) (click on link)
3. Paste the contents into your new `printStatements.java` file in Codespaces
4. Add lines of code and/or comments below each question, testing your code along the way.
1. When complete, upload the file and submit on Canvas. You must get ALL steps correct to get credit (no partial credit).
