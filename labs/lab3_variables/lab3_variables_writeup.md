# CS101 Lab3: Java Variables

## Learning Objectives
In this exercise you will use Java to practice:
- Declaring and initializing variables
- Using data types: `String`, `int`, `long`, `float`, and `double`
- Printing variables to the console
- Performing basic arithmetic with numeric types (`+`, `-`, `*`, `/`, `%`)
- Understanding integer vs double division
- Updating and incrementing variables

---

## Instructions
1. Create a new file in your workspace directory of your Codespaces IDE called `lab3Variables.java`
2. Copy the contents of the [lab3Variables.java](https://github.com/icanhazcodeplz/CS101/blob/main/labs/lab3_variables/lab3Variables.java) (click on link)
