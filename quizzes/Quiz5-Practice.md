**4. (1pt) What does this code print?**
```java
int temp = 32;
if (temp > 50) {
    System.out.println("warm");
} else if (temp > 32) {
    System.out.println("cool");
} else {
    System.out.println("freezing");
}
```
- A) `warm`
- B) `cool`
- C) `freezing`
- D) `warm` and `cool`

**5. (1pt) What does this code print?**


- B) `false`
- C) `5`
- D) Compiler error
