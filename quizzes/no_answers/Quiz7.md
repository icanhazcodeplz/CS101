**1. (2pts) What does this code print?**
```java
int n = 2;
while (n <= 6) {
    System.out.print(" " + n);
    n += 2;
}
```
- A) `2 3 4 5 6`
- B) `4 5 6`
- C) `2 4 `
- D) `2 4 6`

**2. (2pts) What does this code print?**
```java
int n = 1;
do {
    n++;
    System.out.print(" " + n);
} while (n < 4);
```
- A) `2 3 4`
- B) `1 2 3`
- C) `1 2 3 4`
- D) Compile error
